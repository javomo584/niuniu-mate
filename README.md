# 牛牛搭子 NIU NIU MATE

一只常驻桌面、能接住素材、也懂打工人情绪的 AI 办公同事（macOS）。

把内容丢给它，它接住、识别、整理，再把能直接用的结果递回来。

## 下载

前往 [Releases](https://github.com/javomo584/niuniu-mate/releases) 下载最新 macOS 安装包。

> ⚠️ 当前为本地 ad-hoc 签名的 beta 版，未做 Apple Developer ID 签名/公证，首次打开可能被系统拦截，请在「系统设置 → 隐私与安全性」中手动允许。

## 主要能力

- 一口截图（区域 / 窗口 / 全屏 / 长截图）
- 牛牛识字 OCR（本地 Apple Vision）
- 便签 Sticky Notes、批注蹄印
- 剪贴牧场（剪贴板历史）、呼叫条 NiuBar（流式对话）
- 节奏提醒：打卡 / 喝水 / 吃饭 / 久坐，全部可延后 / 暂停 / 关闭
